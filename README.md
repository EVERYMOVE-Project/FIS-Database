# FIS EVERYMOVE Repository

Surveillance-Index
Respository for data cleaning and development of the EVERYMOVE surveillance index incorporating different urban physical activity resources including: exercise facilities, sport courts, municipal sport centers, walkability, and green spaces, for the city of Madrid for the years 2017, 2019, 2021, 2023, and 2025.

Scripts for instalaciones: includes municipal sport centres

Scripts for exercise facilities: includes cleaning of commercial databases from the municipal government

Scripts for walkability: includes data cleaning of four different indicators and their appropriate density calculations

Scripts for parques: includes cleaning of the Urban Atlas dataset for 2018
